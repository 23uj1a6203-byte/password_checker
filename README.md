# password_checker
A Password Strength Checker web application built using Python Flask. It analyzes passwords and classifies them as Weak, Medium, or Strong based on security criteria. The application also provides suggestions to help users create stronger passwords.
Password Strength Checker

A Flask web application that checks password strength and provides suggestions to improve password security.

Features:
- Weak, Medium, Strong classification
- Color-coded results
- Password improvement suggestions

Technologies:
- Python
- Flask
- HTML
- CSS
